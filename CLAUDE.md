# Friendslop

Вся информация для ИИ-разработчика — в `AGENTS.md`. Прочитай его перед работой.

**Если в корне есть `NEXT_UPDATE.md` — это задание на следующее обновление: сделай его, а в конце удали файл (или замени заданием на следующую версию).**

**Главные правила автора:** экономь токены и время — одна чёткая проверка вместо многих; меняй только то, что просили;
сначала согласуй, потом делай; оценивай идеи по настоящим играм. Пуши в `main`, в `release` — только по команде автора.
Онлайн — `docs/ONLINE_PLAN.md`.
