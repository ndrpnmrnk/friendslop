# v0.63.4 - рассинхрон онлайна и голос

02.11.2026. Выпуск в release по команде автора.

## Исправления

- Позиция гостя теперь доверяется его клиенту (матч и хаб). Хост больше не прогоняет её через свою коллизию и задержанные позиции других игроков и не шлёт поправки. Это убирает телепорты у лавочек, дверей и рядом с другими игроками. Ограничение остаётся только при захвате (2 м от держащего).
- Лавочки, качели, зиплайн и крыша автобуса: гость садится на своём клиенте сразу, а не через хост (раньше гость не мог сесть, а у хоста его марионетка «застревала» на месте и занимала лавку). Занятое место определяется и по сетевой позе «сидит». Сидящих не расталкивает разделение персонажей.
- Подбор предметов: хост проверяет подбор с запасом на задержку (3 м, в полёте 3.6 м, без луча), сбрасывает устаревшее «держит» у марионетки. Предсказанный подбор у гостя не откатывается, пока хост не ответил (до 600 мс), для всех предметов, не только миссионных.
- Голос: добавлен второй STUN и поддержка TURN-ретранслятора Cloudflare через `/ice` сервера комнат. Без секретов `TURN_KEY_ID` и `TURN_KEY_API_TOKEN` у Worker работает как раньше (только прямое соединение).

## Проверка

Сборка и `npm run test:online` (94/94). Реальная игра нескольких людей по интернету не проверялась.
