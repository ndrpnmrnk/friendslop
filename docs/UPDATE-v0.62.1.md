# v0.62.1 - входы, плавание, интерьеры и автомат

База main: a868dd27f5d22cd9d7c6ccb43b39b321b59cf676. Только тестовая публикация в main / GitHub Pages. Сервер Worker и release не обновляются.

## Исправления
- Крыша мэрии: вместо слишком большого восьмигранного конуса - неглубокая четырёхскатная крыша по размерам центрального корпуса.
- У новых зданий обычная дверь по умолчанию 1.25 м; общий широкий вход ограничен 2.8 м и имеет две зеркальные створки с петлями на внешних косяках. Состояние пары общее, створки открываются в противоположные стороны. Стеклянные входы открываются автоматически при приближении персонажа; геометрия остаётся распашной, не раздвижной.
- Проверка свободного места теперь разрешает воду только водному транспорту. Уточка и круг не откатываются назад при каждом движении; сохраняют высоту плавания, ограничения берегов и существующие столкновения/таран.
- Велосипеды стоят на свободной стороне велопарковки с отступом 1.35 м. Неподходящие места не используются. Сплошная невидимая коллизия стойки заменена отдельными стойками.
- Почтовые и газетные ящики сдвигаются вдоль фасада, если попадают в зону входа.
- У бизнес-центра удалена отдельно стоящая лестница к люльке. На каждом этаже у лифта выделен вестибюль с боковым проходом, мебель вынесена из подхода.
- Кухни получают границы помещения до создания мебели: шкафы и холодильник ограничены комнатой, задняя стенка примыкает к стене. Кухня верхнего этажа офиса перенесена к восточной стене вне шахты лифта.
- Салат: огурец и помидор являются предметами миссии. Их нужно принести и положить на стол через E; нарезка начинается только когда оба реально лежат на столешнице. Овощ рядом на полу или в руках не считается доставленным. Боты используют ту же столешницу, прежняя нарезка и смешивание сохранены.
- Автомат: бесплатная тренировка и её настройка удалены из доступного управления, старое сохранённое значение не включает её. Попытка стоит прежние 50 фистов.
- Убрано имя игрушки над автоматом. Оставлены прицел, подсветка игрушки и подсказки: левый джойстик/WASD/стрелки, красная кнопка/пробел. Джойстик имеет ненавязчивое световое кольцо во время прицеливания.
- В автомате освобождается курсор; режим исключён из автоматического захвата мыши. Отмена указателя/потеря фокуса сбрасывает движение джойстика.
- Захват повторно проверяет реальное пересечение игрушки. Предварительная цель не может принудительно заменить отсутствующий контакт. При подъёме настоящее физическое тело остаётся в Cannon и поднимается шарниром от текущей позы; удалены принудительное центрирование и выпрямление пойманной игрушки. Механика выдачи в лоток сохранена.
