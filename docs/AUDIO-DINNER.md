# Музыка раунда: DINNER! - Femtanyl

Подготовлено подключение; самого трека в репозитории пока нет.
Официальный источник: https://femtanyl.bandcamp.com/track/dinner
На странице указана покупка цифрового трека и all rights reserved.
Поток прослушивания не извлекался, ремиксы не подставлялись.

Для завершения нужен оригинальный MP3/OGG из разрешённого источника.
После получения положить файл в public/audio/ и указать его относительный путь
в CONFIG.roundMusic.file. До этого поле пустое: загрузки несуществующего файла,
ошибок 404 и изменения музыки опубликованной игры нет.

Поведение уже подготовлено:

- Предварительная загрузка/разрешение воспроизведения при выборе режима.
- Начало оригинальной записи с нулевой позиции вместе с пролётом карты.
- Плавное появление за 0,65 с, gain музыкального канала 0,40.
- По окончании отсчёта переход за 2,4 с к фоновому gain 0,14.
- Скорость записи 1, без обрезки/фильтров; повтор для покрытия всего матча.
- Общий master/mute на M. Остановка в итогах/хабе/меню и перед новым матчем.
- Пауза вместе с игрой в скрытой вкладке или при потере WebGL-контекста;
  продолжение с того же места после возвращения.
- Потоковый HTMLAudioElement, один источник и один GainNode, повторное использование.
- При блокировке autoplay следующая клавиша/клик повторяет запуск без нового интерфейса.

Громкости указаны до общего master игры. Проверка реальной слышимости и совпадения
оригинала возможна после получения файла. Текущая публичная версия остаётся v0.46.

Проверены сборка, настоящее включение main/UI с пустым путём и тесты контроллера:
появление/затухание, один поток, общий mute, повтор матча, пауза/продолжение,
блокировка autoplay/повтор по жесту, остановка/очистка. Аудиофайл не имитируется
другой музыкой, звучание DINNER! ещё не проверялось.
