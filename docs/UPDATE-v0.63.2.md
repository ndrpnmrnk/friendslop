# v0.63.2 - события и мини-карта

Второй небольшой этап утверждённого [плана](../Next%20Update/PLAN.md), 02.11.2026. База - main `860d7d1e53a9219117df20aad2982e793ff794df`. Публикация - main / GitHub Pages.

## Изменения

- Полностью удалены события dark («Отключили свет») и flood («Потоп»): игровые обработчики, UI и иконка потопа, отдельный фонарик, управление затемнением неба и исключение из обычного освещения. Описание режима хаоса больше их не обещает. Получатель игнорирует снимки удалённых событий, не создавая лишней воды или света.
- После удаления остаётся один тип малого события. Выбор теперь допускает повтор единственного варианта и не обращается к пустому списку; классика и марафон сохраняют свои правила. Новый тип события не добавлялся.
- Общие полы тоннелей сохранены как tunnelFloors: ими пользуется и обычная жизнь города. Нейтральная вода, рыбалка, вечерняя погода и прожекторы сохранены.
- На мини-карте дальняя миссия сохраняет свою пиктограмму вместе со стрелкой направления. Ближайшая/главная доступная миссия имеет светлую рамку, остальные приглушены; яркость вторичных значков увеличивается с приближением.
- Близкие значки разнесены. Для ближней сдвинутой пиктограммы остаётся тонкая связь с её настоящим местом, для дальних сохраняется исходное направление. Указатель игрока свободен в проверенных раскладках. Это ограниченная раскладка мини-карты, не полный поиск маршрутов.
- Стрелки ↑/↓ на пиктограмме и возле расстояния в карточке показывают перепад более 2.2 м. Высота столешницы не обозначается другим этажом. Это относительная высота цели, точный номер этажа не вычисляется.
