# v0.69.0 - рассинхрон, взятые предметы, персонажи задом наперёд

03.11.2026. По игре автора вчетвером. Автор разрешил выпустить сразу в release.

## Найденные причины

- **Персонажи ходили задом наперёд** (с v0.68.0). Склейка персонажа после пробного прогона анимаций возвращала поворот кватернионом; разворот на 180° читался как углы (π, 0, π), и дальше код, ставящий `rotation.y`, крутил модель задом. Теперь восстанавливаются углы Эйлера (`characters/merge.js`).
- **Взятый предмет оставался на полу, скейт/самокат отставал от наездника, реквизит миссий «лагал»** (с v0.67.0). В `main.js` комментарий `// v0.67 ...` был вставлен в середину строки и закомментировал вызовы `updateCull()` и `checkFrozen()`. Без `checkFrozen` матрицы подвижных объектов (предметы, транспорт, двери, реквизит миссий) не обновлялись после заморозки статики: логика и сеть работали, а картинка стояла на месте. Без `updateCull` не работало отсечение дальних предметов, NPC, разрушаемого и персонажей (лишние отрисовки и тени). Проверено: в одиночной игре предмет в руке теперь в 1.2 м от персонажа вместо «остался на полу»; в тесте 4 клиентов предмет далеко от руки 76% кадров → 0%.
- **Ошибка кадра при приземлении на скейте/самокате**: вызов несуществующей `shake()` (с v0.67.0) обрывал кадр у наездника при каждом приземлении. Заменено на `shakeCam()`. Проверка `eslint no-undef` по всему `src` - других таких ошибок нет.

## Онлайн

- Свой подбор у гостя: старая «плавная» цель (где предмет лежал) больше не тянет его из руки (`world-sync.forgetVisual`).
- Хост принимает подбор гостя с запасом на задержку (3 → 3.8 м, в полёте 3.6 → 4.4 м): хост видит гостя на 100-250 мс позже.
- Задержка показа чужих персонажей: полтора интервала отправки + два разброса пинга (было около одного интервала), меняется плавно. Опоздавший пакет больше не даёт рывок «догнал-отскочил»; цена - примерно +40 мс к показу.
- Тень склеенного персонажа включается/выключается вместе с остальными деталями (отсечение теней по дальности теперь реально работает).

## Голос

- Настоящий WebRTC-тест (`scripts/online/voice-listen.html`, 3 клиента): говорит один гость, хост и второй гость без микрофона - оба слышат. Код уже позволял слушать без микрофона.

- Новый dev-тест `scripts/online/chaos-smoke.html`: хост + 3 гостя, у гостей задержка 70-170 мс с пиками, все бегают и прыгают, гости носят/бросают предметы и катаются на самокате, 3 бота. Итог: предмет далеко от руки 0%, транспорт отдельно от наездника 0%, состояние предметов расходится с хостом дольше 0.8 с - 0%, ошибок кадра 0, рывки чужих персонажей сильнее их настоящего шага - 0.5% кадров (до фиксов 1-6%).
- `npm run test:game` 44/44, `npm run test:online` 55/55, сборка, скриншот ходьбы.
