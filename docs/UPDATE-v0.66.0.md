# v0.66.0 - взаимодействие, голос, меню, производительность

02.11.2026. По списку автора.

## 1. Тесты

- `test:online` - только сеть: сервер комнат, аккаунты (вход через Discord с подменой Discord, профиль, слияние гостевого прогресса), протокол, сглаживание движения, репликация, монеты, радио, телеметрия. 55 тестов, ~20 с.
- `test:game` - 44 теста контента (скейтпарк, утиная лодка, машины, освещение хаба, каталог миссий, кулаки). Запускать только при правках этих частей.
- Нагрузочный тест больше не запускается в обычной проверке (`test:stress`).
- `smoke.html`: проверка «очки ровно один раз» ждёт прихода очков и решает пазл не быстрее человека (хост не засчитывает миссию быстрее 0.1 с).

## 2. Игроки друг с другом

- Удар по игроку другого компьютера: у атакующего сразу вспышка, звук, поза падения/отлёта цели; настоящее состояние приходит следом (`net/hit-predict.js`). Матч и хаб.
- Удар гостя идёт цели напрямую через сервер (`phit`), минуя хост: цель применяет у себя, хост - для ботов и выпавшего из рук предмета.
- Захват у гостя виден сразу (подтверждение хоста до 0.6 с); того, кого держишь, рисуем у своих рук.

## 3. Голос и бумбокс

- Микрофон уходит в WebRTC прямой копией трека (затвор - включение трека), без прохода через WebAudio; захват с эхо- и шумоподавлением, автоусилением, моно.
- Голосовые пакеты с высоким приоритетом, минимальный буфер приёма; восстановление связи через 3 с потери, а не только после полного обрыва.
- Голоса друзей слышны на любом расстоянии (ближе - громче, минимум 35%); игрок без модели рядом слышен без направления.
- Бумбокс: поправка темпа не больше ±0.8% без растяжения звука, мёртвая зона 0.12 с, сглаженное измерение рассинхрона - без «плавающей» музыки.
- Замер `voice-latency.html` (локально, синтетический микрофон): нажал V → слышно у друга 70-90 мс, без провалов; это нижний предел WebRTC, по интернету добавляется пинг.

## 4. Прочий онлайн

- Разовые действия гостя (взять, бросить, дверь, захват, сесть и т.д.) уходят хосту сразу отдельным событием, не ждут пакета состояния (до 12 в секунду). Миссии - обычным пакетом ради порядка.

## 5. Esc и мышь

- Esc открывает меню с первого нажатия и в хабе, и в матче; повторное событие Esc не закрывает его обратно.
- Повторный захват мыши после Esc: браузер ~1 с отклоняет его - игра повторяет попытку в пределах того же клика, лишние клики не нужны.
- Колесо мыши забирается игрой только при захваченной мыши; в меню оно прокручивает список.

## 6. Меню настроек

- Одна компактная панель слева везде (главное меню, хаб, матч): шапка с закрытием, прокрутка внутри (плавная, тонкая полоса), разделы ИГРА / ГРАФИКА / ЗВУК / МИКРОФОН раскрываются плавно, раскрытый внизу раздел сам подтягивается в видимую область. Проверено на 1280×720, 1920×1080, 900×480, 390×800.

## 7. Производительность

- Кэш значений uniform на уровне WebGL: three.js заново слал массивы (вспышки света, матрица тени) на каждый вызов отрисовки. Минус ~1050 обращений к драйверу за кадр.
- Тени: детали меньше 12 см не рисуются в проходе теней (−25% отрисовок прохода); на «Высокой» тени обновляются 40 раз/с вместо 60.
- Высота пола: толкаемые предметы по клеткам 4 м вместо перебора всех на каждый запрос; монеты сталкиваются только с движущимися предметами; боты ищут дверь/стекло на пути 8 раз/с.
- Логика игры без рендера (7 ботов, 9 районов): 4.2 → 2.7 мс на кадр. Реальный FPS на видеокарте здесь не измерить (только программный рендер).
