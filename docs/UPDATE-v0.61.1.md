# v0.61.1 - прежнее подтягивание на уступ

По просьбе автора удалены зацеп за край, висение на руках, отдельное нажатие для подъёма/отпускания и сброс при наступании на руки.

Игроки и боты снова автоматически подтягиваются на доступный уступ, как в v0.60.17. Сохранены проверка свободного пути, коллизии, плавная анимация подъёма и остальные изменения v0.61.0.

Проверка: сборка Vite и целевой CPU-сценарий районов/миссий с раундом на 7 ботов; вместо висения он теперь проверяет автоматическое завершение подъёма на высокий уступ без дополнительного ввода. Среда без WebGL - реальный FPS этим тестом не измеряется.

Публикация: main / GitHub Pages. Ветка release не меняется.
