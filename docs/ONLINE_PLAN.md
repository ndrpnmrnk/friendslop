# Онлайн Friendslop — план (согласован с автором 28.10.2026)

Этот файл — для любой ИИ, которая продолжит работу. Районы и миссии идут по `NEXT_UPDATE.md`, онлайн — по этому файлу.
Делать онлайн в отдельной ветке; почти весь код — в новых папках `worker/` (сервер) и `src/net/` (сеть в игре),
в `main.js` / `menu.js` — только небольшие точки подключения.

## Где живёт игра
- Код: GitHub `ndrpnmrnk/friendslop`, ветка `main`.
- Сайт 1 (основной для игры с друзьями): **https://friendslop-6h1.pages.dev** — Cloudflare Pages, подключён к GitHub,
  сам собирается при каждом пуше в `main` (`npm run build`, папка `dist`, `NODE_VERSION=22`). Домен пока не покупаем.
- Сайт 2 (запасной): https://ndrpnmrnk.github.io/friendslop/ — GitHub Actions → GitHub Pages, тоже из `main`.
- Сервер комнат (будет): Cloudflare Worker + Durable Objects из папки `worker/` этого же репозитория.
  Подключает автор в панели Cloudflare (Workers → Import repository), ИИ готовит код и пошаговую инструкцию.

## Лимиты Cloudflare (бесплатный тариф) — знать и беречь
- **Сайт (Pages)**: открывать игру можно сколько угодно — статические файлы лимитов не тратят.
  Лимит один: **500 сборок в месяц** (каждый пуш в `main` = 1 сборка). Поэтому пушить в `main` пачками, не по мелочи.
- **Сервер комнат (Durable Objects)**: **100 000 запросов в день** и **13 000 ГБ·с в день**, сброс в 00:00 UTC
  (02:00/03:00 по Киеву). Подключение = 1 запрос; входящие сообщения WebSocket считаются 20 к 1.
  - 8 игроков × 20 сообщений/с ≈ 8 запросов/с ≈ 29 000 в час → **≈3–3.5 часа игры ввосьмером в день**;
    вдвоём ≈ 7 000 в час → больше 12 часов. Сервер в простое (никто не играет) лимит не тратит.
  - Экономия: отправлять ввод и снимки 15–20 раз/с, склеивать мелкие события в одно сообщение, не слать, если ничего
    не изменилось, комната «засыпает», когда все вышли.
  - Если лимит кончился — до сброса не создаются/не работают комнаты; сам сайт и одиночная игра работают.
    Если станет мало — платный тариф Workers ~$5/мес.
- Проверки ИИ: локально (`vite preview` + playwright) и тестовым сервером `wrangler dev` — они лимиты не тратят.

## Решения автора
- **Ник**: при входе игрок сам вводит ник в красивой панели в стиле игры (пиксельный шрифт, рамка, «живое» поле,
  подсказка, запоминается в браузере). Ники видны над персонажами:
  - пиксельный шрифт; чем ближе персонаж — тем крупнее и ярче, далеко — не видно (плавно исчезает);
  - **не видно сквозь стены**: ник закрывается домами/стенами, как сам персонаж (проверка по глубине/лучу).
- **Вход**: хост жмёт «Создать лобби» → код из 4 символов (например `K7QX`); друзья вводят код и появляются рядом
  с хостом в хабе. До 8 человек в комнате.
- **Хост вышел** → матч заканчивается, все возвращаются в хаб (без передачи хоста).
- **Кто считает игру**: браузер хоста (мир, физика, боты, миссии). Остальные шлют хосту ввод и получают снимки
  мира 15–20 раз/с со сглаживанием. Сервер ничего не считает — только пересылает сообщения в комнате.
  Карта не передаётся: всем рассылается «зерно» карты, каждый строит её сам.
- Домен — пока `friendslop-6h1.pages.dev`.

## Этапы
0. ✅ Сайт на Cloudflare Pages (28.10).
1. **Сервер комнат** (`worker/`): Durable Object `Room` на код комнаты; создать/войти/выйти, список игроков (ник, скин),
   хост, максимум 8, пинг, переподключение по токену, защита от спама созданием комнат, проверка версии игры
   (у всех должна быть одна версия — иначе «обнови страницу»).
2. **Вместе в хабе**: панель ника; «Создать лобби / Войти по коду»; друзья появляются в хабе со скинами и никами;
   синхронно бег, прыжки, эмоции, речь, гардероб (смена скина видна всем); мяч голосования общий (считает хост);
   рогатка запускает всех вместе.
3. **Матч**: хост рассылает зерно карты и режим; все строят карту; хост считает мир и ботов (боты занимают пустые места);
   ввод клиентов → хост; снимки → клиенты; интерполяция.
4. **Миссии, предметы, транспорт, финал**: броски, захваты, фишки районов, очки, повтор и пьедестал у всех одинаковые.
5. **Надёжность**: хост вышел → конец матча и возврат в хаб; обрыв у клиента → переподключение; слабый интернет.
