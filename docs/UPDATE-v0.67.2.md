# v0.67.2 - оптимизация отрисовки

02.11.2026. По замеру автора: 61 FPS, кадр упирается в процессор (рендер 14.5 мс JS, 978 отрисовок).

- Собаки: туловище было разбито на группы материалов по одному треугольнику - ~75 отрисовок на собаку. Теперь треугольники одного окраса подряд: 3 группы, ~10 отрисовок на собаку, вид тот же.
- Разрушаемые (ящики, стёкла, заборы): раньше одна инстанс-группа на вид детали по всей карте - её границы покрывали город, и она рисовалась всегда. Теперь BatchedMesh: один вызов на материал в участке 48×48 м, детали отсекаются поштучно, далёкие участки скрываются. Ломание/восстановление работают как раньше.
- Склейка одинаковых объектов перед кадром: полная перегруппировка раз в 3 кадра (между ними только позиции), на видеокарту уходят только сдвинувшиеся матрицы. Стоимость 7.5 → ~4.3 мс в тестовом браузере.
- Отсечение по дальности: двери 34 м (почти все внутри зданий), NPC 46 м, участки разрушаемых 62 м; всё с поправкой пресета.
- Тени обновляются 10 / 20 / 30 раз в секунду (низкая / средняя / высокая) - каждый проход теней - полный обход сцены.
- Замер на одной карте и в один момент: основной кадр 645 → 475 отрисовок (-26%).
- Проверка: test:online 55/55, test:game 44/44, smoke, проверка ломания и восстановления разрушаемых, снимок кадра.
