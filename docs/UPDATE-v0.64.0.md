# v0.64.0 - аккаунты: вход через Discord или гостем

02.11.2026. Согласовано с автором.

## Что сделано

- Первый экран: основная кнопка «Войти через Discord», второстепенная «Играть как гость». После входа - одна кнопка «ИГРАТЬ» и плашка аккаунта (аватар, ник, «выйти») слева вверху.
- Гость: как раньше, всё хранится в этом браузере, ник задаётся вручную.
- Discord: ник и аватар берутся из Discord, ник можно сменить (свой ник больше не перезаписывается Discord). Прогресс хранится на сервере и одинаков на любой ссылке и в любом браузере: коллекция персонажей, выбранный персонаж, кулаки, рекорд и награда паркура, пройденное обучение и подсказка броска. Настройки графики, звука и микрофона остаются у каждого устройства свои.
- Первый вход в браузере объединяет гостевой прогресс этого браузера с аккаунтом (персонажи складываются, кулаков берётся больше, рекорд - лучший). Выход очищает прогресс в браузере, в аккаунте он остаётся.
- Аватар Discord виден в списке лобби.

## Устройство

- Сервер комнат: `worker/src/accounts.js`, Durable Object `Accounts` (SQLite, миграция v2). Маршруты `/auth/discord`, `/auth/discord/callback`, `GET/PUT /account`, `POST /account/logout`.
- Секреты Worker: `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`. Redirect в Discord: `https://friendslop-rooms.andrey-ponomarenko-06-24.workers.dev/auth/discord/callback`.
- Токен сессии приходит в игру во фрагменте адреса и хранится в браузере; на сервере - только его SHA-256. Сессия живёт 180 дней с последнего входа, до 10 браузеров на аккаунт.
- Клиент: `src/boot.js` загружает профиль до запуска игры, `src/net/account.js` - синхронизация, `src/ui/account-ui.js` - кнопки и плашка.

## Проверка

Сборка, `npm run test:online` 94/94, локальная проверка API аккаунтов в Miniflare (вход, чтение, сохранение, свой ник, выход), скриншот первого экрана. Настоящий вход через Discord возможен только после настройки приложения Discord и выпуска сервера в release.
