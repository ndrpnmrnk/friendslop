# v0.58.2 — срочное исправление

- Взятые предметы и транспорт снова двигаются вместе с персонажем. Причина — ускорение из v0.57: подвижные объекты
  (предметы, тележки, скейты, двери) попадали в «застывшие» ветки сцены, и three.js не пересчитывал их положение
  на экране — предмет в руках, а картинка лежит на месте. Теперь застывает только по-настоящему неподвижное.
