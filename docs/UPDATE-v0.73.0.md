# v0.73.0 — план N (04.11.2026)

Только `main` / GitHub Pages. В release не выпускалось.

## Хаб
- Табло: шрифт меньше, имена целиком (сжатие по ширине), без ряби.
- HUD: всё с одной стороны, счётчик деталей с новой 3D-пиксельной иконкой рядом с фистами (скрыт до 1 уровня). Уровень свалки убран.
- Автомат с игрушками: при наведении на игрушку захват гарантирован, игрушка подвешивается кинематически (без лагов физического шарнира).
- Шайба: дальше скользит от толчков, в воротах резко тормозит.
- Сани: турбина пересобрана без совпадающих граней (нет ряби), убраны мешок/подарок/чёрный диск. Камера запуска: общий план, «GoPro» сзади-сбоку на борту с тряской, фиксированная боковая камера, следящая за санями; камера не проходит сквозь геометрию.

## Свалка (src/ui/hub-junk.js — переписана)
- Детальные PS1-модели: кучи хлама, печь, верстак, гараж, дирижабль, ящики с парашютом; декор свалки запечён (машины, контейнер, погрузчик, шины, бочки).
- Ворота: решётка с замком и «1 УР» по центру; при открытии поднимается, взрывается на обломки и исчезает навсегда.
- Призраки будущих построек: полупрозрачный контур + 3D-плашка (цена в деталях/фистах, замок и уровень, «E» когда хватает).
- Цены: печь — 2 ур., 60 деталей; верстак — 3 ур., 200 деталей + 20 фистов; гараж — 4 ур., 500 деталей + 50 фистов. Куча даёт 3–8 деталей (блестящая — больше).

## Персонаж
- Анимации заново: бег (кривые шага, запаздывание рук, наклон), перекат (ease-in-out, группировка), подкат, новое подтягивание (руки на краю, колено вверх).
- Отскок от стены: пробел у стены в прыжке, 1 раз за полёт, 15% стамины.

## Матч
- Заставки событий до ~5 с, камера проверяется лучом и не застревает в геометрии; для лавы — вулкан на краю карты с извержением.
- Метель — настоящая буря: затемнение, белая мгла, больше снега, позёмка, периодические порывы ветра.
- Небо: кольцо дымки в цвет тумана (тёмный город снизу больше не выделяется днём), единые пиксельные объёмные облака в хабе и матче.
