# Радио Friendslop

Музыка раунда добавлена отдельно от радио: `dinner-femtanyl.mp3` - присланный
автором оригинал DINNER! - femtanyl, 136.49 с, stereo 44.1 kHz, без перекодирования.
SHA-256: `e6015b801e18c4d9de59c9d10b74d3fc4588f2a20cd8f203419df0339c6f0447`.
Фоновое воспроизведение не получает фильтры бумбокса. Переход между повторами
смешивается в памяти, исходный файл не изменяется. Настройки: `CONFIG.music`.

Три записи предоставлены автором игры для бумбокса:

| Файл | Станция | Запись | Длительность |
| --- | --- | --- | --- |
| chocolate.ogg | 88.3 | Третий шоколадный | 2:28 |
| family.ogg | 96.7 | Семейный круг | 3:06 |
| little.ogg | 104.2 | Мелкий | 3:23 |

Сохранены полные записи. Обработка: high-pass 150 Hz, low-pass 5500 Hz,
мягкий bitcrusher 10 bit с примесью 30%, limiter 0.85; mono 16 kHz, Ogg Vorbis q2.
Исходные MP3 и их метаданные в сборку не включены. Общий размер записей около 2.1 MB.
Шипение настройки синтезируется отдельно и не прибавлено к самим записям.

Исходник хранится бинарными частями в `audio-src/dinner/`, чтобы передавать его
через GitHub без большого запроса. Скрипт `scripts/prepare-audio.mjs` собирает
полный MP3 перед dev/build; сгенерированный файл исключён из git.
